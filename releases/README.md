## 🚀 How to Install

1. Download [`Nidham_0.1.0_x64-setup.exe`](./Nidham_0.1.0_x64-setup.exe).
2. Double-click the installer to launch the setup wizard.
3. Follow the quick on-screen instructions (takes less than 5 seconds).
4. Launch **Nidham** from your Desktop or Start Menu!

## 💡 System Requirements

- **Operating System:** Windows 10 / Windows 11 (64-bit)
- **Runtime:** Microsoft Edge WebView2 (pre-installed on all modern Windows 10 & 11 systems)
- **Network:** 100% offline capable — all data stored locally on your machine
